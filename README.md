# Day Type Motivation App

A simple Node.js application built with Express.js and EJS that dynamically displays messages based on whether the current day is a weekday or a weekend.

---

## 🚀 Features
- Detects the day using JavaScript `Date`
- Displays different messages for weekdays and weekends
- Uses EJS templating to render dynamic content
- Clean and beginner-friendly backend logic

---

## 🛠 Tech Stack
- Node.js
- Express.js
- EJS
- JavaScript
